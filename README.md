# 📢Projeto 1 - AniTrack

# Ideia do sistema (qual problema resolve):
Resolver a dificuldade que os fãs de cultura pop têm em organizar seu progresso em obras longas. O sistema evita que o usuário se perca em quais episódios, temporadas, filmes ou arcos já foram assistidos, centralizando tudo em um único lugar. 

# Breve descrição de como o sistema vai funcionar:
O sistema será uma aplicação web (SPA). Existirão usuários comuns e administradores. O administrador poderá cadastrar novas obras (animes, séries ou jogos) no catálogo global da plataforma. O usuário comum fará login e poderá adicionar essas obras à sua "Lista Pessoal", atualizando seu status (Ex: "Assistindo", "Pausado", "Finalizado") e a quantidade de episódios vistos.
